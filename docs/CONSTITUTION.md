# Конституция Chezilla

Набросок. Он фиксирует стек и ограничения, по которым принимается первый ход диалога. Это не спецификация поведения: поведение хода описано в issue и в `GLOSSARY.md`.

## Стек

Каноническая среда разработки — контейнер `dev` из `compose.yaml`, образ Python 3.12. Отдельный интерпретатор на машине для проверки не нужен.

Ход диалога — пакет `chezilla` на стандартной библиотеке. Сторонних библиотек у хода нет. В контейнер для проверки ставятся только pytest и mypy. mypy запускается в строгом режиме из `pyproject.toml`.

Векторная база, LangChain и LlamaIndex не выбраны. ХЗЧЗ для хода — значение, которое ход читает. Поиск по эмбеддингам в этот шаг не входит.

## Ограничения

Советник не подаёт сведения в систему маркировки и не действует от имени пользователя. Это решение записано в `docs/adr/0001-advisor-does-not-submit.md`.

Ход диалога ХЗЧЗ не изменяет.

Проверка поведения идёт на одном шве: вход хода — дата вопроса, состояние диалога, сообщение и ХЗЧЗ; выход — ответ и новое состояние диалога. Канал (веб или MAX) этот шов не ветвит.

Имена в коде и в проверках берутся из `GLOSSARY.md`.

## Сборка и проверка

Из корня репозитория:

```bash
make build
make test
make typecheck
make check
```

`make build` собирает образ `chezilla-dev`. `make test` прогоняет pytest. `make typecheck` прогоняет mypy. `make check` делает оба прогона. `make` вызывает `docker compose`, а если этой команды нет — `docker-compose`. Код смонтирован в контейнер, поэтому правка исходников не требует новой сборки, пока не меняется `pyproject.toml`.
