# Советник не подаёт сведения

Chezilla — Советник для Ответственного за маркировку: он называет действующее требование и следующий шаг. Подача сведений в систему маркировки в этот продукт не входит. Риск необратимой ошибки в государственной системе несовместим с ценностью Советника, чей ответ можно проверить по источникам.

## Границы и будущее развитие

Текущий продукт — только Советник, без подачи сведений. Если позже понадобится автоматизация подачи данных, это будет отдельный продукт с независимой проверкой и независимым развёртыванием, не расширение chezilla. Причина та же: риск необратимых операций несовместим с ценностью Советника. Текущее решение эту автоматизацию не запрещает и место под неё не занимает — оно резервирует её за отдельным продуктом.

## Considered Options

- Добавить подачу сведений в chezilla, когда появится спрос. Отклонено: необратимую операцию нельзя принести в продукт, ценность которого — проверяемый ответ.
